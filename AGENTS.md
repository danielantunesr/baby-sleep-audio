Apply ASD-STE100 (Simplified Technical English, Issue 9) in these cases:

1. Status reports: when you tell the user what you did.
2. Documents: when you write a document to save information
   (README, notes, specs, changelogs, docs).

Key rules:

- Use short sentences. Procedures: 20 words maximum. Descriptions: 25 words maximum.
- One topic for each paragraph.
- Use the active voice. Use the imperative in instructions.
- Use approved words only, with their approved meaning and part of speech.
- Use one word for one meaning. Do not use synonyms for variety.
- Use only these verb forms: infinitive, simple present, simple past,
  future, imperative, past participle.
- Do not stack more than 3 nouns.
- Use articles (the, a, an) and keep full sentences.

Language: ASD-STE100 is for English. Write in English when this standard applies.
Reply to the user in the language of the user's message. Keep chat answers
(not reports or documents) in that language.
